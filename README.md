# AppHotel

Aplicativo de gerenciamento de reservas de hospedagem, desenvolvido com **.NET MAUI** e **C#**.

## Sobre o projeto

O AppHotel é um aplicativo desenvolvido com o objetivo de facilitar o processo de cadastro e organização de reservas de hospedagem.

A aplicação permite registrar informações dos hóspedes, selecionar acomodações, definir datas de entrada e saída e consultar as reservas cadastradas por meio de uma interface simples e intuitiva.

## Funcionalidades

- Cadastro de hóspedes;
- Seleção do tipo de acomodação;
- Definição das datas de check-in e check-out;
- Seleção da quantidade de hóspedes;
- Validação das informações da reserva;
- Listagem das reservas cadastradas;
- Tela informativa sobre o aplicativo.

## Tecnologias utilizadas

- **C#** — linguagem utilizada na programação da aplicação;
- **.NET MAUI** — framework para desenvolvimento de aplicações multiplataforma;
- **XAML** — linguagem utilizada na construção das interfaces;
- **Visual Studio** — ambiente de desenvolvimento.

## Estrutura do projeto

O projeto está organizado em arquivos responsáveis pela interface visual, lógica de funcionamento, modelo de dados, recursos gráficos e configurações específicas das plataformas.

## Como executar o projeto

1. Clone este repositório;
2. Abra o arquivo `AppHotel.sln` ou `AppHotel.csproj` no Visual Studio;
3. Verifique se o .NET MAUI está instalado e configurado;
4. Compile e execute a aplicação em uma plataforma compatível.
